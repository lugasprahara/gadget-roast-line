One line, at most 200 characters, roasting a gadget used every day: a robot vacuum that mapped the whole home and named every room, yet spends its afternoons trapped under the sofa. The program in `main.ts` holds the line, checks it fits the gate (a single line of 1–200 characters), and writes it to `/output/entry.txt` — that text is the whole entry.

## Run it

```sh
node main.ts
```
